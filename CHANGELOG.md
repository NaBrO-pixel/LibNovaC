# Changes

## 0.3

0.2 covered files, processes and signals. 0.3 makes libNovaC a C library
that ordinary programs can be built against. It adds floating point
throughout, a math library, and wrappers for every system call NovarisOS's
kernel already offered.

### Floating point

- **printf.** The conversions `%f %F %e %E %g %G %a %A` (and `L`) are
  exact: they print from the exact decimal expansion of the value (via big
  integers) with ties-to-even rounding.
- **Parsing.** `strtod`, `strtof`, `strtold` and `atof` are correctly
  rounded for decimal input of any length, hex floats, `inf`/`infinity` and
  `nan(...)`, and set `ERANGE` on overflow and underflow.
- **scanf.** A new engine (`<novac/scan.h>`) serves `sscanf`, `fscanf`,
  `scanf` and their `v` forms. It handles every C conversion including
  `%[`, `%n`, `%p` and the float conversions, plus `*`, field widths, all
  length modifiers, and POSIX `m` (allocate).

### `<math.h>` and `<fenv.h>`

- **Functions.** The exp/log families, `pow`, `sin`/`cos`/`tan` (Payne-Hanek
  reduction for huge arguments), the inverse and hyperbolic functions,
  `cbrt`, `hypot`, `sqrt`, rounding, `fmod`/`remainder`/`remquo`,
  decomposition, `nextafter`, `fmin`/`fmax`/`fdim`, and the classification
  macros.
- **Accuracy and variants.** The double functions are within an ulp. The
  float forms are rounded from double, and the long double forms compute at
  double precision. Errors are reported through `errno`, and all of Annex
  F's special cases are handled.
- **`<fenv.h>`.** Rounding modes and exception flags, kept in step on SSE
  and x87.

### More of the standard library

- **`<string.h>` and `<strings.h>`.**
  - New functions: `strtok`/`strtok_r`, `strsep`, `strspn`/`strcspn`/`strpbrk`,
    `strdup`/`strndup`, `stpcpy`/`stpncpy`, `strlcpy`/`strlcat`, `memmem`,
    `memrchr`, `memccpy`, `mempcpy`, `strchrnul`, `strcasestr`,
    `strcoll`/`strxfrm`, `strerror_r` (XSI), `strsignal`, `explicit_bzero`,
    `strcasecmp`/`strncasecmp`, `bzero`/`bcmp`/`bcopy` and `ffs`.
  - `memcpy`, `memset`, `memmove`, `memcmp`, `strlen` and `memchr` now work
    eight bytes at a time.
- **`<errno.h>`.** It now has every Linux error number, and `strerror`
  returns glibc's text for each (generated by `tools/gen_errno.py`).
  `strerror(ENOMEM)` is now "Cannot allocate memory".
- **`<stdlib.h>`.**
  - Allocation: `aligned_alloc`, `posix_memalign`, `memalign`,
    `reallocarray`, `malloc_usable_size`.
  - Random numbers: `rand_r`, `random`/`srandom`, the POSIX `drand48`
    family (the same sequences as glibc), and `arc4random`,
    `arc4random_buf` and `arc4random_uniform`.
  - Exit: `quick_exit`/`at_quick_exit`.
  - Other: `qsort_r`, `clearenv`, `system`, `mkstemp`/`mkostemp`/`mkstemps`,
    `mkdtemp` and `realpath`.
- **`<stdio.h>`.**
  - Streams now have pluggable backends, through GNU `fopencookie`.
  - New streams: `fmemopen`, `open_memstream`, `fdopen`, `freopen`,
    `tmpfile`, `popen`/`pclose`.
  - New functions: `getline`/`getdelim`, `asprintf`/`vasprintf`,
    `dprintf`/`vdprintf`, `fseeko`/`ftello`, `fgetpos`/`fsetpos`,
    `setbuf`/`setlinebuf`, `renameat`, and the `*_unlocked` and `flockfile`
    forms.
  - `fread` and `fgets` copy whole buffers at a time.
  - Reading stdin flushes stdout first, so prompts appear.
- **`<time.h>`.** `strftime`, `localtime`/`localtime_r` (UTC), `asctime`,
  `ctime`, `clock`, `clock_getres`, `clock_nanosleep`, `timespec_get`,
  `tzset`, and `tm_gmtoff`/`tm_zone` in `struct tm`.
- **New headers.**
  - `<setjmp.h>`: `setjmp`/`longjmp` and `sigsetjmp`/`siglongjmp`.
  - `<getopt.h>`: `getopt_long` and `getopt_long_only`, with GNU-style
    argv permutation.
  - Also `<fnmatch.h>`, `<libgen.h>`, `<inttypes.h>` and `<locale.h>`
    (the "C" locale only).

### System interfaces

These are new wrappers for calls the kernel already implemented, each
syscall number checked against `syscall64.h`.

- **Networking.** BSD sockets (`<sys/socket.h>`, `<netinet/in.h>`,
  `<netinet/tcp.h>`, `<arpa/inet.h>`, `<sys/un.h>`) and numeric
  `getaddrinfo`/`getnameinfo` (`<netdb.h>`).
- **Waiting and memory.** `poll`/`ppoll`/`select`/`pselect`, and
  `mmap`/`mprotect`/`msync`/`madvise`.
- **Files and descriptors.**
  - `readv`/`writev` and `pread`/`pwrite`.
  - `fcntl`.
  - The `*at()` family: `openat`, `mkdirat`, `fstatat`, `unlinkat`,
    `renameat`, `faccessat`, `symlinkat`, `readlinkat`.
  - `symlink`/`readlink`, `chmod`/`fchmod`/`umask`, `utimensat`/`futimens`,
    `truncate`, `fsync`/`fdatasync`, `dup3`, `fchdir`.
- **Processes and identity.** `setsid`, the uid/gid calls, `pause`,
  `usleep`, the `execl` family and `execvpe`.
- **Signals.** `sigsuspend`, `sigpending`, `sigtimedwait`/`sigwaitinfo`/`sigwait`,
  `sigaltstack`, `siginterrupt`, `killpg`, `psignal`, and the rest of the
  Linux signal numbers.
- **System information.** `uname`, `gethostname`, `sysconf`,
  `getrlimit`/`setrlimit`/`prlimit`, `getrusage`, `times`, `gettimeofday`,
  `getrandom`/`getentropy`, and `getauxval` (crt0 now records the
  auxiliary vector).
- **Terminals.** `isatty`, `ioctl`, and `<termios.h>`.
- **Directories.** `fdopendir`, `dirfd`, `rewinddir`, `telldir`/`seekdir`,
  and `scandir`/`alphasort`.
- **Wait status.** The full set of macros (`WIFSTOPPED`, `WCOREDUMP`, ...).

### Build and tests

- **check-sysnum.** `make check-sysnum` works on its own, against a
  vendored `syscall64.h` (`third_party/novaris/`).
- **Link check.** `make link-check`, which `target-test` runs first, links
  every object in the archive, so an undefined symbol or a libgcc helper
  cannot hide in code no test happens to use.
- **Example.** `make example` now builds a runnable static demo.
- **Host tests against glibc.** The host tests compare with glibc on
  random inputs:
  - printf's float conversions and `strtod`/`strtof`, including exact
    halfway cases;
  - the math functions, measured in ulps;
  - `inet_pton`/`inet_ntop`/`inet_aton`;
  - `getopt_long`, including the final argv order;
  - `fnmatch`, `strftime`, `gmtime` and `drand48`.
- **Target test.** It gains a second part (`novac_target_v03.c`) covering
  the 0.3 system interfaces: sockets over the loopback, `mmap`, streams,
  `setjmp`, signals and the `*at()` calls.

## 0.2

0.1 was written against an earlier kernel and had no way to use what
NovarisOS could by then do. 0.2 added:

- **Signals.** `<signal.h>` arrived, with an `rt_sigreturn` trampoline as
  the handlers' return address (`SA_RESTORER`), so a handler that returns
  resumes the interrupted code.
- **`abort()` raises `SIGABRT`.**
  - In 0.1 it exited with status 134, so a parent saw a normal exit.
  - Now it unblocks and raises `SIGABRT`. If a handler catches it and
    returns, the default action is restored and the signal is raised again.
  - The exit status remains only as a fallback, and is all the host unit
    tests (which have no signals) see.
- **`execve`, `execv` and `execvp`**, the last searching `PATH` (default
  `/bin:/usr/bin`).
- **`setenv` and `unsetenv`.** The environment is copied into memory of
  its own the first time it changes.
- **New definitions:** `ESRCH`, `ETXTBSY`, `EDEADLK`, `ENOLCK`, and
  `PATH_MAX`.

Running the target test inside NovarisOS for the first time found four
places where the kernel differed from Linux. All were fixed in the kernel:

- `mkdir` on an existing path succeeded instead of failing with `EEXIST`.
- `open` ignored `O_DIRECTORY`.
- `open` ignored `O_EXCL`.
- The `siginfo` of a signal sent with `kill` or `tgkill` said `SEGV_MAPERR`
  instead of `SI_USER`/`SI_TKILL`, and carried no `si_pid`.
